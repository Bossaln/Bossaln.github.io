🆘 Passwort zurücksetzen

Einen der ausgedruckten Wiederherstellungs-Codes eingeben und ein neues Passwort vergeben. Jeder Code gilt genau einmal.

Kein Code mehr da? Dann hilft nur der Weg über den Server selbst – am Raspberry Pi: sudo bash deploy/passwort-setzen.sh

🔑 Passwort ändern

Die heruntergeladene Datei zugang.json in den Ordner daten/ hochladen – erst dann gilt das neue Passwort. Es wird nur ein sicherer Prüfwert (Hash) gespeichert, nie das Passwort selbst.

🆘 Wiederherstellungs-Codes

Für den Fall, dass das Passwort einmal vergessen wird: Mit einem dieser Codes lässt sich auf der Anmeldeseite ein neues Passwort setzen – ohne Umweg über die Kommandozeile. Am besten ausdrucken und dorthin legen, wo auch die anderen wichtigen Unterlagen liegen. Jeder Code gilt genau einmal.
